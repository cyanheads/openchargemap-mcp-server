# 0.2.0 — 2026-10-26

## Added

- Publish openchargemap-guide through the MCP Skills extension as a discoverable skill resource.

## Changed

- **Search pagination** reuses one cached pool of 500 candidates across offsets and page sizes; a 501st record detects an upstream remainder without entering results or counts ([#18](https://github.com/cyanheads/openchargemap-mcp-server/issues/18), [#31](https://github.com/cyanheads/openchargemap-mcp-server/issues/31)).
- **Empty search and reference results** return successful empty lists with query/filter echoes and recovery notices instead of `no_stations` or `no_match` errors ([#30](https://github.com/cyanheads/openchargemap-mcp-server/issues/30)).
- **Oversized page sizes** clamp to 200 stations or 100 comments/reference entries, with a notice, log and counter; `OPENCHARGEMAP_CLAMP_LIMITS=false` restores rejection ([#32](https://github.com/cyanheads/openchargemap-mcp-server/issues/32)).
- **Markdown output** preserves upstream text literally and renders media and link fields as images and links.
- **Packaging and tooling** add Agent Plugins root manifests, deliver the guide in npm, Docker and MCPB, and exclude development files, dependency agent docs and native-build intermediates from MCPB. Framework scripts and development skills match 0.13.18; Bun images and package-manager metadata move 1.4.2 → 1.4.4, with a one-day dependency age floor.

## Fixed

- **CCS guidance** names both regional connector IDs, 32 and 33, rather than suggesting Type 2 alone ([#21](https://github.com/cyanheads/openchargemap-mcp-server/issues/21)).
- **Unknown country codes** are disclosed as unrecognized and unapplied, with guidance to resolve a valid code ([#22](https://github.com/cyanheads/openchargemap-mcp-server/issues/22)).
- **Zero-valued reference IDs** are accepted for connector, usage and status filters, including array inputs ([#23](https://github.com/cyanheads/openchargemap-mcp-server/issues/23)).
- **Connector alias lookup** treats prototype-property queries such as `constructor` as ordinary queries instead of crashing ([#24](https://github.com/cyanheads/openchargemap-mcp-server/issues/24)).
- **Station evidence** preserves connector status, operational flags and equipment notes on both output surfaces ([#25](https://github.com/cyanheads/openchargemap-mcp-server/issues/25)).
- **Reliability notes** describe all comments on record and their latest dated entry without presenting historical faults as recent ([#26](https://github.com/cyanheads/openchargemap-mcp-server/issues/26)).
- **Provider licensing** preserves per-station license text and explicit open-data flags; attribution no longer asserts a blanket CC BY 4.0 license ([#27](https://github.com/cyanheads/openchargemap-mcp-server/issues/27)).
- **Comment rendering** includes metadata-only rows with their dates, authors and types, matching structured output ([#28](https://github.com/cyanheads/openchargemap-mcp-server/issues/28)).
