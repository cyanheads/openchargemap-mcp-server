# 0.2.1 — 2026-11-19

## Added

- **`find_stations` route search**: `route` takes 2–500 points with `distance` as the corridor half-width; each station carries `routeDistance` and `offRouteDistance`. Legs spanning 180° of longitude or more, corridors that would cross a pole or ±180° (the hint names the widest `distance` that fits), and over-long requests are refused ([#37](https://github.com/cyanheads/openchargemap-mcp-server/issues/37)).
- **Station contact and usage fields**: `get_station` returns contact fields (withheld for private residences) and `dateCreated`; search rows carry `usageTypeId` and `usageCost`, and addresses `line2` ([#38](https://github.com/cyanheads/openchargemap-mcp-server/issues/38)).
- **Provider license terms** are listed once per search page in the text output, keyed by the new `dataProviderId` ([#39](https://github.com/cyanheads/openchargemap-mcp-server/issues/39)).

## Changed

- **Caller-facing descriptions** no longer name the operator-only `OPENCHARGEMAP_CLAMP_LIMITS` setting or a nonexistent "free" usage type; the page-cap rejection states the cap ([#40](https://github.com/cyanheads/openchargemap-mcp-server/issues/40)).
- **Docs**: README, `docs/design.md`, the `openchargemap-guide` skill (1.0 → 1.1), and the Codex plugin description cover route search and the changes above.

## Fixed

- **Permanent upstream rejections** (400, 404, 414, 422, 501, …) fail once as non-retryable `upstream_unavailable` with their own recovery hint instead of being retried; a route search that times out upstream also fails once, with a hint to send fewer points. Caller cancellation passes through untouched.
- **Retry timing**: one 50 s deadline bounds each fetch's whole retry ladder, including an attempt in flight, and Open Charge Map's `Retry-After` paces retries and reaches the caller as `retryAfter`.
- **Bounding boxes** run as a distance search from the box's center to its farthest point, filtered back to the box, so no station outside a wide box is returned and none inside is missed; `sw_lng > ne_lng` spans ±180° ([#34](https://github.com/cyanheads/openchargemap-mcp-server/issues/34)).
- **Result order** is distance, then station ID, in every mode, and the remainder notice states how far the retrieved stations reach (radius, box, or route variants) ([#35](https://github.com/cyanheads/openchargemap-mcp-server/issues/35)).
- **`lookup_reference`** matches word starts (CamelCase and letter–digit sub-words, separator-insensitive, optional leading "the") in four rank tiers with ascending-ID ties, and aliases countries and charge levels beside connectors, so "UK" no longer resolves to Ukraine ([#36](https://github.com/cyanheads/openchargemap-mcp-server/issues/36)).
- **`lookup_reference`** resolves non-Latin names (Cyrillic, Greek, Arabic) and folds letters such as ø, ı, ð, æ, ß to their Latin base.
- **Radius searches** cover the full requested radius; the upstream search circle fell 0.11% short.
- **A truncated response body** from a dropped connection is reported as a network error, not invalid JSON.
- **Placeholder coordinates**: records stored at or a few metres off 0,0 are dropped from search and flagged on `get_station`.
- **Search-row `distance`** carries the same hundredths-rounded value in `structuredContent` as in the text.
- **Operator without a title** shows its operator ID in the text output.
- **The no-match notice** advises relaxing `minchargepoints` only when it was set, rather than "the other filters", which run upstream and never empty the retrieved pool.
