# 0.1.0 — 2026-06-13

Initial release. A find-and-detail MCP server over the community-maintained [Open Charge Map](https://openchargemap.org) registry, built on `@cyanheads/mcp-ts-core`.

## Added

- **`openchargemap_find_stations`** — find EV charging stations near a point (latitude/longitude/distance) or within a bounding box, filtered by connector type, minimum power, operator, usage type, charge level, operational status, and minimum charge points. Coordinate-native — geocode place names with the openstreetmap server first.
- **`openchargemap_get_station`** — full record for one station by numeric OCM ID (`verbose=true`): every connection, operator, usage/access restrictions, charge points, general comments, usage cost, media, and a computed plain-prose reliability note. Optional inline community comments.
- **`openchargemap_lookup_reference`** — resolve connector/operator/usage/status/country names to the integer filter IDs `find_stations` needs, served from a bundled snapshot (offline, instant); curated connector aliases (`CCS`, `NACS`/`Supercharger`, `J1772`, `Type 2`). Browse a full category with no query.
- **`openchargemap_get_station_comments`** — community check-ins for one station alongside the registry status and last-verified date, so registry-vs-reality mismatch is visible.
- **`openchargemap://station/{id}`** resource — the detail tool's URI-addressable twin.
- Bundled reference snapshot (`src/data/ocm-reference-data.ts`) with an optional startup refresh from `/referencedata` gated by `OPENCHARGEMAP_REFERENCE_REFRESH` (bundled-snapshot fallback on failure).
- Config: `OPENCHARGEMAP_API_KEY` (required), `OPENCHARGEMAP_BASE_URL`, `OPENCHARGEMAP_REFERENCE_REFRESH`.
- CC BY 4.0 attribution to Open Charge Map contributors surfaced in every tool's output and the server-level instructions, per the data license.
