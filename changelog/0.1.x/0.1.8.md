# 0.1.8 — 2026-08-25

## Added

- **`openchargemap://station/{id}` `output` schema and 600s `cacheHint`** — the resource now declares and validates its return shape (shared `DetailStationSchema` with `openchargemap_get_station`) and advertises a 600s cache lifetime, matching the service's own station-record cache.
- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`** — contribution guide (server-vs-framework triage, agent-filing workflow) and conduct policy.

## Changed

- **Tool inputs are strict at the root** (`@cyanheads/mcp-ts-core` `^0.12.3`) — a call carrying an argument key none of this server's tools declare is now rejected by name (`unrecognized_keys`) instead of the key being silently stripped.
- **Advertised schemas move to JSON Schema 2020-12 and declare the error envelope** (`^0.12.3`) — `outputSchema` now models the `error` branch, so a client validating `structuredContent` without checking `isError` stops mis-rejecting failed calls.
- **Dockerfile build stage cross-compiles** — pinned to `--platform=$BUILDPLATFORM` and Bun `1.4.0` (was `1.3.14`), avoiding a JavaScriptCore allocator abort when Bun ≥1.4 runs under QEMU on a multi-arch `linux/amd64` build (mcp-ts-core#370). Production installs add `--omit=peer`, dropping framework optional peers this server doesn't import.
- **`.env.example`** — `MCP_SESSION_MODE` set explicitly to `stateless`, matching the shipped container; the framework default moved to `auto` (→ `stateful`).
- **`.github/SECURITY.md`** — vulnerability contact moved to `security@caseyjhand.com`.

## Fixed

- **`renderComment`** — a comment whose text already includes its `relatedUrl` link no longer repeats the URL a second time in the rendered line.
