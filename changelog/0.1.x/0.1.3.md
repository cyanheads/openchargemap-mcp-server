# 0.1.3 — 2026-06-20

## Changed

- **`scripts/devcheck.ts`, `scripts/build-changelog.ts`, `scripts/check-framework-antipatterns.ts`, `scripts/check-skill-versions.ts`** — synced from mcp-ts-core 0.10.7: fresh-scaffold guards so git-dependent checks (`git grep` / `git ls-files`) and the changelog rollup skip cleanly before `git init`, and `check-skill-versions` tolerates a `SKILL.md` pruned from the worktree. ([cyanheads/mcp-ts-core#237](https://github.com/cyanheads/mcp-ts-core/issues/237), [#242](https://github.com/cyanheads/mcp-ts-core/issues/242), [#243](https://github.com/cyanheads/mcp-ts-core/issues/243))
- **Fourteen `skills/<name>/SKILL.md`** — re-synced to the 0.10.7 framework bodies (seven carried `metadata.version` bumps: `api-auth`, `api-errors`, `api-services`, `api-telemetry`, `field-test`, `report-issue-local`, `tool-defs-analysis`). ([cyanheads/mcp-ts-core#238](https://github.com/cyanheads/mcp-ts-core/issues/238))

## Added

- **`scripts/check-dependency-specifiers.ts`** — new devcheck step (from mcp-ts-core 0.10.9) hard-failing on floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json` dependency sections and `bun.lock` workspace maps. Static and local; runs in the default and `--fast` passes. ([cyanheads/mcp-ts-core#246](https://github.com/cyanheads/mcp-ts-core/issues/246))
- **Plugin marketplace manifest checks in `lint:packaging`** — `scripts/lint-packaging.ts` check 10 validates `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, and `.codex-plugin/mcp.json` for non-empty descriptions, unscoped display names, and the full scoped name in the `npx -y` install arg. Enabled via the new `devcheck.config.json` `packaging.pluginManifests` flag. ([cyanheads/mcp-ts-core#240](https://github.com/cyanheads/mcp-ts-core/issues/240))
